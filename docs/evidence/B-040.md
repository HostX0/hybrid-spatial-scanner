# B-040 — no automatic capture upload

## Scope

`hss::privacy` is a small, side-effect-free policy contract for captured
artifacts, project archives, exports and diagnostics. Capture, save, reopen and
ordinary export decisions always return `kKeepLocal`; the compile-time contract
sets `kAutomaticUploadEnabled` to `false`. The module has no filesystem,
socket, HTTP, cloud or third-party dependency and therefore cannot upload a
private scan while evaluating a decision.

A future sharing surface must provide the exact selected artifact IDs,
destination and explicit user confirmation. The policy rejects empty or
unknown selections and missing confirmation. It requests a preview before an
explicit share and makes the distinction between a user-selected file
destination and an external share visible to the caller. Operating-system
backups and file providers remain outside the app's control and are not
silently promised away.
