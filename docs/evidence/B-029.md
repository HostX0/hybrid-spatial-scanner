# B-029 — Provenance presentation slice

## Delivered

`HSSApp/ProvenanceUI/ProvenancePresentationModel.swift` defines a reusable
field-level contract for the five required origins: observed, fitted,
user-measured, inferred, and unknown. It carries source, uncertainty, and
accuracy-validation disclosure separately. A user measurement that lacks a
source or stated uncertainty remains visibly incomplete.

`ProvenanceAccuracyDisclosure` defaults to `notMeasured`; the only alternate
state requires an `IndependentReferenceComparison`, including the comparison's
reference description and reference uncertainty. The view therefore says
"Not measured against an independent reference" for all unverified values and
uses "Reference comparison" only when the producer supplies the independent
comparison payload. This UI does not calculate values, fit geometry, or make
accuracy claims.

`HSSApp/ProvenanceUI/ProvenanceDisclosureView.swift` renders a compact,
accessible SwiftUI disclosure card with text and symbols in addition to color.
The slice contains its own English/Arabic `ProvenanceCopy` values pending the
native integrator's localization wiring; shared `.strings` files were not
changed.

`tests/ProvenancePresentationTests.swift` covers bilingual copy, the safe
default accuracy disclosure, and the source/uncertainty requirement for user
measurements. It is intentionally not registered in the Xcode project because
this packet must not edit project wiring; the native integrator must add the
new source files and focused test to the app/test targets.

## Validation

Run from this worktree:

```sh
xcrun swiftc -parse HSSApp/ProvenanceUI/ProvenancePresentationModel.swift \
  HSSApp/ProvenanceUI/ProvenanceDisclosureView.swift
xcrun swiftc -parse tests/ProvenancePresentationTests.swift
git diff --check
```

The parse checks verify syntax for the source slice and focused test. They do
not compile an iOS target because Xcode project registration is deliberately
outside this packet.

## Integration and device limits

The integration owner must map accepted engine/project provenance, reference
measurement source and uncertainty, and independently validated comparison
results into `ProvenanceFieldPresentation`; it must not synthesize an
`IndependentReferenceComparison` from an estimate. It must also add the files
to their Xcode targets and replace the temporary bilingual values with the
product localization mechanism.

No simulator build, iPhone deployment, ARKit/RoomPlan capture, physical
measurement, independent metrology comparison, accessibility session, or
Arabic usability test was performed. This packet makes no sensor accuracy,
repeatability, completeness, or release-readiness claim.
