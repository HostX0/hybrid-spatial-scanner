# B-002 evidence — native application and portable core scaffold

## Delivered

`HSSApp/` contains a native SwiftUI iOS application target with a deliberately
honest readiness screen. `SpatialCore/` contains a dependency-free C++20
static-library foundation. The same source is built by the Xcode `SpatialCore`
target and CMake `SpatialCore` target. `Tests/` holds a small app-shell test.

The project has an iOS 17.0 deployment target, Swift 6 language mode, and
capability-gated application behavior. It has no signing settings, external
dependencies, capture session, RoomPlan integration, sensor adapter, geometry
generation, or implementation of the normative `hss_api.h` facade. B-009 owns
that facade/engine implementation.

## Reproduce

From the repository root, with Xcode 27.0 (27A266a):

```sh
xcodebuild -project HSSApp/HybridSpatialScanner.xcodeproj -scheme HybridSpatialScanner -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project HSSApp/HybridSpatialScanner.xcodeproj -scheme HybridSpatialScanner -sdk iphoneos -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

For the portable core and existing reference checks, with CMake 3.31.6 from
the coordinator-provided virtual environment:

```sh
/Users/abdulazeez/Documents/Codex/2026-09-22/pf-x20/work/host-venv/bin/cmake -S . -B build/core -DHSS_BUILD_TESTS=ON
/Users/abdulazeez/Documents/Codex/2026-09-22/pf-x20/work/host-venv/bin/cmake --build build/core --config Debug
/Users/abdulazeez/Documents/Codex/2026-09-22/pf-x20/work/host-venv/bin/ctest --test-dir build/core --output-on-failure
```

Observed on 2026-09-22: both generic iOS destinations built successfully;
the simulator `build-for-testing` compilation also succeeded. CMake configured
with AppleClang 21.0.0.21000334, built `SpatialCore`, and CTest passed 2/2
(`abi_smoke`, `cpp_math`).
