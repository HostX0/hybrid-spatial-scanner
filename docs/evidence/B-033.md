# B-033 evidence — frozen PDF/SVG artifacts

Date: 2026-09-22

`hss::pdf_svg_export` accepts value-owned B-031 `PlanLayer` and resolved B-032
`Layout` data only when both name the same accepted scene revision. It emits
deterministic in-memory PDF, SVG, and UTF-8 manifest bytes. The persistence
owner can therefore freeze these bytes inside its manifest-last export job;
live scene mutations cannot change an already-built artifact.

The SVG has a metre-derived `viewBox`, declares exactly one Y inversion, and
keeps boundary, dimensions, and warnings as groups. Its manifest retains
fragment support IDs, annotation evidence IDs, availability, UTF-8 labels, and
warnings. A fragment without an explicit segment remains in the manifest but
does not receive an invented vector path. PDF contains vector paths, revision
metadata, scale bar, and `Print at 100%` caveat. Explicit-scale output rejects
overflow rather than silently cropping.

for rendered Arabic PDF text. No hardware, printer, or external PDF/CAD
consumer validation was run.
