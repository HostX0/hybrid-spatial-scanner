# B-032 evidence — revision-bound annotation geometry

Date: 2026-09-22

`hss::annotation_geometry` accepts an already assembled B-031 `PlanLayer` and
returns only annotation geometry tied to that layer's exact scene revision and
retained fragment/support IDs. Linear, height, angle, and label annotations
retain caller-supplied anchors in metre coordinates. The module never snaps,
extends, projects, closes, or otherwise repairs those anchors.

Observed and fitted measurements are computed only from explicit anchors and
require retained evidence IDs. User values are accepted only when identified as
an explicit user measurement. Unknown and inferred sources remain provisional
with no numeric value. Labels have no numeric value. This avoids deriving a
measurement from a semantic label or filling missing geometry.
