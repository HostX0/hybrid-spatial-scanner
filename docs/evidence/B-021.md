## Delivered portable module

`hss::ceiling_overhead::classify` validates caller-declared, source-backed
ceiling and overhead patches, then copies them into separate collections for
ceiling patches, soffit bottoms, soffit returns, floating shelves and unknown
regions. It does not infer roles, fit planes, create floor obstructions or
complete missing geometry.

Plane normals and offsets are retained exactly after finite, unit-normal,
project-extent and caller-declared support-distance checks. There is no gravity,
axis, Manhattan or single-height prior. Plane support must contain at least
three non-collinear finite metric points, and every point references retained
depth-frame or mesh-anchor provenance. Captured meshes require finite bounded
vertices, valid nondegenerate triangles and metric provenance.

Unknown regions have a boundary and explicit no-depth provenance, but no plane,
mesh or metric-support payload. An unknown cannot use observed/fitted origin,
and a ceiling/shelf surface cannot use unknown origin. The result type keeps
unknown regions structurally separate from surface patches. A floating shelf
has its own output collection and the module has no floor-obstruction output.

All input collection sizes have caller limits and compile-time hard ceilings.
Invalid options, identities, enum values, provenance, geometry, source support,
meshes, roles and unknown regions have explicit statuses. Every failure returns
an empty optional model; allocation and unexpected failures are also converted
to no-partial statuses.

## Focused synthetic coverage

`fixtures/ceilings/sloped_coffer_skylight.hpp` supplies authored synthetic
evidence for an oblique ceiling plane, a lower coffer/soffit bottom, a vertical
return, a captured floating-shelf mesh and an open-sky/no-depth region. The
focused test verifies that all five remain separate, arbitrary plane values and
source lineage round-trip exactly, and local ceiling heights are not collapsed.

Negative cases cover observed or filled unknowns, absent no-depth provenance,
degenerate unknown boundaries, unknown surface evidence, off-plane support,
insufficient/duplicate support, nonfinite and out-of-bounds geometry, broken
support provenance, invalid mesh indices, no-depth-only shelf support, invalid
options, collection limits, duplicate/zero IDs and invalid enum values. Every
case asserts that no partial model is returned.
