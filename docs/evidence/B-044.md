## Delivered host golden suite

`tests/hss_golden_suite_test.cpp` composes the public portable C++ APIs from
B-022, B-024, and B-031. It reads its newly authored inputs only from
`tests/fixtures/golden/`, apart from the B-024 canonical starting scene
`fixtures/scenes/scene.example.json` that is intentionally reused to exercise
the revisioned command processor against its established scene contract.

The tests make these deterministic assertions:

- `oblique_protected_rib.csv` is an authored oblique protected chain. Every
  segment carries explicit protection and retained support; a supported
  coordinate refinement succeeds, while removal fails atomically without a
  candidate snapshot. Position locking remains independent of topology
  protection.
- `oblique_rib_with_hole.csv` has a 0.150 m front on a narrow rib, an oblique
  outer surface, and a clockwise detached fixed-obstruction hole. With the
  stated synthetic provenance, the B-031 plan layer publishes the authored
  29.775 m2 net result from a 29.925 m2 outer ring and a 0.150 m2 hole. This
  asserts deterministic ring consumption and classification, not scan
  measurement accuracy.
- `semantic_uncertainty.csv` produces an explicit unknown-boundary layer. It
  retains no metric segment, returns unavailable/null area, and names the
  `unknown_boundary_evidence` issue. It does not create geometry from the
  semantic uncertainty.
- `revisioned_undo.ndjson` drives B-024's public `Processor` through split,
  undo, and redo. Undo appends a compensating journal record naming the exact
  original command, removes the deterministic split lineage from the restored
  model, and redo restores that same lineage in a later revision.

All fixture coordinates and expected values are explicitly synthetic. The
suite does not use an iPhone capture, hidden geometry, generated measurement
data, or sensor-derived physical reference.

## Scope and limitations

This is a portable synthetic regression suite for declared API invariants. It
does not integrate these standalone modules into `hss_engine`, C ABI, schemas,
storage/checkpointing, Swift/Xcode, export, replay, or the AR capture path. It
does not establish topology detection, physical width/depth/area accuracy,
independent observation support, calibration, thermal behavior, or usability.
ENG-13's held-out physical metrology, device, and operator evidence remain
separate acceptance work; passing this synthetic lower-layer suite does not
complete them.
