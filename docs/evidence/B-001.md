# B-001 evidence — synthetic fixture baseline

Acceptance target: review the known rib contour and the 29.925 m² fixture
(coordination backlog B-001 / TC-001). The paired detached-column fixture is
also checked because it is the documented net-area variant.

## Commands executed

```text
python3 -c 'import json; from pathlib import Path
def area(p): return abs(sum(x*y2-x2*y for (x,y),(x2,y2) in zip(p,p[1:]+p[:1])))/2
for f in ["fixtures/scenes/rib_050_015.json","fixtures/scenes/rib_with_column.json"]:
 d=json.loads(Path(f).read_text()); outer=area(d["outer"]); holes=sum(area(h) for h in d["holes"]); print(f, "outer=%.6f holes=%.6f net=%.6f expected=%.6f"%(outer,holes,outer-holes,d["expected_area_m2"])); assert abs(outer-holes-d["expected_area_m2"])<1e-12'
```

Observed output:

```text
fixtures/scenes/rib_050_015.json outer=29.925000 holes=0.000000 net=29.925000 expected=29.925000
fixtures/scenes/rib_with_column.json outer=29.925000 holes=0.150000 net=29.775000 expected=29.775000
```

The independent standard-library shoelace calculation passes both expected
values. The outer contour contains the two rib returns and narrow front in its
declared order; the second fixture subtracts exactly 0.150 m² for the detached
column hole.
