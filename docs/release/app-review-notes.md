# Hybrid Spatial Scanner — App Review notes

Publisher and app support: THE THIRD ACT LLC. Email Hello@the-3rdact.com;
US telephone +1 (719) 286-7476.

No sign-in, demo account, purchase, subscription, advertising or cloud
reconstruction service is required for the implemented offline workflows.
Room capture requires an actual supported LiDAR device with scene depth and
mesh reconstruction, camera permission, usable storage and normal tracking.
Object capture and reconstruction have separate hardware support checks.
Unsupported capture is explained rather than presented as an equivalent scan.

## Main journey

1. Open the local library and choose **New room scan**. Name the room.
2. Read the readiness checks and authorize the camera when you choose to scan.
3. Start capture. Move slowly and keep visible room detail in view. Pause or
   finish to review the current result, its 2D/3D views and linked issues.
4. Plans require a supported floor reference and coherent, supported boundaries.
   Missing evidence remains visible and may leave area unavailable.
5. For a supported current boundary target, use the offered review actions.
   Feature protection is separate from confirmed position locking. A reference
   dimension records its source and uncertainty. A stale correction or undo is
   explained instead of applied to a different target.
6. Save the accepted revision and reopen it from the library. Export formats
   offered for the current evidence can be shared using the system share sheet.

Source color is an optional appearance of verified captured geometry. Unsupported
views remain neutral. Including used source photographs in 3D exports is off by
default and requires an explicit choice. Room archives do not include those color
photographs. Object models are shared separately from retained object source
photographs.

## Privacy and support

From the library, the shield opens **Privacy and local data**, including the full
policy link. The question-mark button opens **Help and support**, with bundled
offline help, email/phone contact and public support links. No scan or diagnostic
file is attached automatically. There is no app account to delete. Room projects
are recoverable in Trash until permanent deletion; object sessions are removed
separately. Previously shared files and device backups are outside local deletion.
