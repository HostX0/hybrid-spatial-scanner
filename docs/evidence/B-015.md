## Delivered portable fitting module

`hss::plane_fit::fit` is a standalone C++20 geometry module. It selects a
robust three-point candidate with a repository-owned deterministic generator,
then performs iterative weighted total least squares on threshold-supported
samples. It applies no axis, gravity, category, or Manhattan prior. The
largest-magnitude normal component is positive (ties use x, y, then z), the
normal is unit length, and zero-valued output fields are canonical positive
zero.

The caller must provide a positive inlier distance threshold. The API does not
encode 0.02 m, claim that a threshold is sensor accuracy, or infer physical
accuracy from synthetic residuals. Each sample carries an explicit positive
weight and correlated-observation diversity group. Successful output includes
the selected source indices, raw and distinct support counts, summed weight,
in-plane major/minor variance, diversity-group count, weighted RMS/median/max
absolute residuals, and actual iteration/evaluation counts.

Failure is atomic: the optional plane is empty for invalid tuning, nonfinite or
invalid weighted input, insufficient evidence, collinear/near-rank-deficient
support, exhausted work limits, nonconvergent refinement, or unsafe numeric
intermediates. Exact duplicate coordinates do not increase distinct spatial
support. The implementation has hard and caller-declared caps for samples,
candidate iterations, refinement iterations, and residual evaluations; the
work budget is validated before candidate scanning. These are computational
bounds, not a claim about device frame time.

This task adds no candidate-merging operation. A focused fixture presents two
independently supported parallel grids separated beyond the caller threshold;
the larger grid is selected and every returned source index remains on that
grid. Parallel orientation alone does not combine their support.

## Focused coverage

`hss_robust_plane_fit_test` covers:

- seeded deterministic fitting of a noisy oblique plane with 35 outliers;
- exact repeatability, finite unit/canonical output, residual summaries,
  distinct support, sample weights, and observation diversity;
- a direct unequal-weight versus equal-weight refinement check;
- separated supported parallel planes with explicit nonmerged source indices;
- near-collinear rank rejection and exact-collinear hypothesis rejection;
- repeated identical coordinates that cannot inflate distinct support;
- insufficient, nonfinite, undeclared-threshold, and work-budget failures with
  no partial plane.

The first focused sanitizer run showed that ranking diversity ahead of spatial
support allowed scattered outliers to win. Candidate ordering was corrected to
prioritize distinct spatial support, then total support, diversity, minor
variance, and residual. The clean runs below include the repaired behavior.

## Scope and tests not run

The new fitter is not wired into `hss_engine`, normalized replay, the
provisional plan, durable storage, bounded ingress, Swift, Xcode, schemas, or
the public C ABI. No iPhone/simulator build, ARKit/RoomPlan session, physical
capture, sensor replay, performance/thermal test, metrology, reconstruction,
save/reopen, export, or device timing test ran. Synthetic plane residuals do
not establish physical dimensional accuracy. Future scene-pipeline integration
must choose thresholds, weights, diversity groups, and scheduling limits from
declared evidence quality and validate them on held-out captures and measured
fixtures.
