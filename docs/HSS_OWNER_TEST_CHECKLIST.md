# قائمة تحقق مخططة للمالك — Hybrid Spatial Scanner

**الحالة اليوم:** التطبيق غير جاهز للاختبار الفيزيائي. لم تُنفّذ أي خانة أدناه. لا يوجد هنا ادعاء بوجود build موقّع أو Team أو جهاز مُسجّل. يبدأ الاختبار على iPhone 15 Pro Max فقط بعد إعلان جاهزية build قابل للتثبيت عبر Xcode.

## قبل البدء (لاحقاً عند إعلان الجاهزية)

- [ ] تأكيد commit التطبيق، إصدار iOS، اسم الجهاز، واسم المخطط `HybridSpatialScanner` في Xcode.
- [ ] تثبيت build على iPhone 15 Pro Max عبر Xcode بعد إعداد Team والجهاز من قبل المالك؛ سجّل القيم الفعلية ولا تخمّنها.
- [ ] منح إذن الكاميرا صراحة، والتحقق من دعم World Tracking و`sceneDepth` وإعادة بناء mesh، وحالة الجاهزية ومساحة التخزين.
- [ ] إنشاء سجل run ورقم scene قبل الالتقاط. احتفظ بمجموعة tuning ومجموعة held-out منفصلتين؛ لا تستخدم نتائج held-out لتعديل الإعدادات.
- [ ] تحديد نقاط القياس وتعريف كل endpoint، وقياس المرجع المستقل ثلاث مرات على الأقل. سجّل المتوسط/الوسيط، التشتت، ومرجع عدم اليقين `u_ref` والتسامح المعلن.

## مسار المشاهد

- [ ] غرفة صغيرة مستطيلة: أطوال الجدران، الارتفاع/المستوى، القطر، وإغلاق الحدود.
- [ ] زاوية مائلة (acute/obtuse): زاوية مرجعية ومقدّرة، الأطوال، وإغلاق بلا افتراض Manhattan.
- [ ] rib أو عمود ضيق: العرض والعمق وظهور الوجهين والعودة القصيرة؛ سجّل أي وجه مفقود.
- [ ] فتحة/ثقب (باب أو نافذة): حدود الفتحة وعرضها/ارتفاعها/عمقها، وبقاء الفراغ.
- [ ] رف أو بروز منخفض: الارتفاع والعرض واكتمال السطح؛ لا تُقبل مساحة كلية سليمة إذا فشل هذا التفصيل.
- [ ] ممر/قاعة أطول أو مشهد مختلط مع حجب: تحريك مطلوب، relocalization، تغيّر epoch، والفجوات.

## القياس والسلوك

- [ ] لكل بعد: `x_ref`، `x̂`، الخطأ الموقّع والمطلق، `u_ref`، والتسامح؛ سجّل pass/fail/blocked/not applicable لكل endpoint.
- [ ] كرّر المشهد نفسه وسجّل spread/SD أو range؛ افصل repeatability عن accuracy.
- [ ] تحقق من mesh add/update/remove، المحاور والوحدات، اتجاه portrait/landscape، وتطابق overlay مع epoch الحالي.
- [ ] احفظ دون شبكة، أغلق وافتح من جديد، ثم صدّر offline. تحقق من بقاء revision والـ warnings والهندسة، وسجّل اسم الملف/checksum.
- [ ] اختبر interruption (خلفية/مكالمة/إذن) واسترجاعه، ثم افحص ضغط التخزين.
- [ ] نفّذ **وضع object منفصلاً** عن مسح الغرفة، وسجّل النتيجة كمسار مستقل.
- [ ] في جلسة لاحقة: راقب 20 دقيقة للحرارة/الأداء، وسجّل المدة والحالة. افحص VoiceOver، Dynamic Type، التباين، أهداف اللمس، الدوران، وRTL بالعربية.
