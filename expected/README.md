# Synthetic expected outputs

These authored SVG, DXF and OBJ examples demonstrate metres, the inward rib contour and export sidecars. They are not outputs of a completed scanner. DXF uses AC1015, INSUNITS=6 and a one-metre reference line. OBJ has 16 vertices and 16 wall triangles with a synthetic 3 m height; it intentionally has no floor/ceiling closure or textures. All coordinates are fixtures, not measurements. External CAD/viewer interoperability remains untested.
